# Featured Projects 🚀

### [Meteo-data](https://github.com/YuzuruTK/Meteo-data)
A meteorological data platform with scheduled ingestion from multiple providers, historical storage, a React dashboard, REST endpoints, and rainfall notifications.  
**TypeScript · Cloudflare Workers · D1 · React · Vite**

### [Zoho Personal Integration](https://github.com/YuzuruTK/zoho-personal-integration)
A personal assistant integration connecting Zoho Calendar and OpenCode through the Model Context Protocol (MCP), with event search, availability calculations, and a private web chat.  
**Node.js · TypeScript · Zoho API · MCP · Docker · SQLite**

### [FASTA2GO](https://github.com/YuzuruTK/FASTA2GO)
A bioinformatics pipeline for protein sequence processing, feature extraction, UniProt annotation integration, and preparation of Gene Ontology labels for molecular function prediction.  
**Python · DuckDB · BioPython · Pandas · scikit-learn**

### [Thought Box API](https://github.com/YuzuruTK/thought_box_api)
An AI-assisted knowledge management application with a REST API and web interface for structured information, summaries, and Markdown document generation.  
**TypeScript · React · Cloudflare Workers · Hono · D1 · Drizzle ORM**
